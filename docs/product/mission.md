# 미션: gopepe-calc (포지션 계산기)

- 최종 갱신: 2026-11-25

## 문제
USDT 마진 무기한 선물에서 수익 중인 포지션에 미실현 수익을 재투입해 추가 진입(피라미딩)하기 전에 "몇 번 더 들어가면 평단·청산가·실효 레버리지가 어떻게 되고, 익절·손절하면 수수료를 빼고 얼마가 남나"를 한 화면에서 시뮬레이션해 보고 싶다. 거래소 계산기는 진입 한 번의 손익·청산가만 계산하고, 단계별 추가 진입과 그 결과는 보여 주지 않는다. 숫자를 바꾸면 결과가 바로 바뀌는 거래 터미널형 화면이 필요하다. [사용자 결정] (2026-11-25 개정: 개별 계산기 묶음에서 피라미딩 화면 하나로 바꿈)

## 대상 사용자
거래소(Bybit·Binance) 계산기를 써 본 USDT 무기한 선물 트레이더. ROE, 격리/교차, 청산가 같은 용어를 이미 안다. [사용자 결정]

## 차별점
- 거래소 계산기에 없는 피라미딩(수익 재투입 추가 진입) 시나리오를 최초 진입부터 익절·손절까지 한 화면에서 본다: 단계별 평단·청산가·실효 레버리지, 수수료 포함 본전가·순손익, 단일 진입 대비 비교, 손절 전 청산 경고. [사용자 결정]
- 로그인 없이 거래소 밖에서 바로 쓴다. 손익·평단·청산가는 Bybit 공식 문서의 공식을 바탕으로 하고, 심볼의 유지증거금률·최대 레버리지를 자동 적용한다. 수수료를 반영한 청산가는 추정치이며 그렇다고 고지한다. [사용자 결정]

## 하지 않을 것
- 실제 주문 실행이나 거래소 계정 연동 — 시뮬레이션 전용이다. [제안 후 승인]
- 화면에서 실시간 가격·거래소 API 호출 — 심볼 정보는 파일에 수기로 적는다. [제안 후 승인]
- 입문자용 용어 설명·교육 콘텐츠. [제안 후 승인]
- 코인 마진(인버스) 선물, 헤지 모드. [제안 후 승인]
- 회원가입·로그인·서버 저장. [제안 후 승인]
