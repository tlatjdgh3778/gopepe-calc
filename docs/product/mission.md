# 미션: gopepe-calc (포지션 계산기)

- 최종 갱신: 2026-11-19

## 문제
USDT 마진 무기한 선물 포지션을 잡기 전에 "이 가격에 이 수량·레버리지로 들어가면 손익·목표가·청산가·평단이 어떻게 되나"를 빠르게 시뮬레이션해 보고 싶다. 이 계산은 거래소 계산기 안에만 있어 거래소 화면을 열어야 한다. 복리 계산기처럼 숫자를 넣으면 결과가 바로 나오는 편의 도구가 필요하다. [사용자 결정]

## 대상 사용자
거래소(Bybit·Binance) 계산기를 써 본 USDT 무기한 선물 트레이더. ROE, 격리/교차, 청산가 같은 용어를 이미 안다. [사용자 결정]

## 차별점
- 거래소와 같은 계산을 거래소 밖에서 로그인 없이 바로 할 수 있다. 같은 입력이면 거래소 계산기와 같은 숫자가 나온다. [사용자 결정]
- 거래소 계산기에 없는 불타기(수익 재투입 추가 진입) 시나리오로 단계별 평단·청산가·실효 레버리지를 볼 수 있다. [사용자 결정]

## 하지 않을 것
- 실제 주문 실행이나 거래소 계정 연동 — 시뮬레이션 전용이다. [제안 후 승인]
- 화면에서 실시간 가격·거래소 API 호출 — 심볼 정보는 파일에 수기로 적는다. [제안 후 승인]
- 입문자용 용어 설명·교육 콘텐츠. [제안 후 승인]
- 코인 마진(인버스) 선물, 헤지 모드. [제안 후 승인]
- 회원가입·로그인·서버 저장. [제안 후 승인]
